# 产品与业务边界

> Status: **Active** | Owner: **Product** | Reviewed: 2026-10-14

## 目标

足球俱乐部多端系统服务家长、教练和俱乐部运营。重庆天才微信小程序为已导入、可鉴权的数据提供原生任务流：家长查看孩子日程、训练/比赛结果、成长、课时与保障；教练查看职责范围内的训练/比赛、点名、计划与评测。后台管理/WPS/Excel 接入属于独立能力，不把管理员接口直接暴露给小程序。

## 不可退让的业务原则

- 会话角色从后端 active membership 与 app-client capability 判定；家长/教练身份不可由客户端猜测或手选伪造。
- 家长仅看合法 guardian binding 的孩子，不显示其他家庭数据；教练只操作获授权团队和活动。
- 所有人数、金额、余额、分数、排名、统计和状态必须来自真实 API/持久化读回；未接入能力只能真实空态/阻塞，不使用 Figma 演示数字。
- 目前“点名即扣课”；旧独立销课/课时更正设计处于历史状态，不能从旧画板重新引入。详情以 [在线 Figma 映射](../current/figma-source-of-truth.md) 和实际契约校验。
- 页面采用微信原生任务流，适度克制动效；克制不意味着可以简化或替换已批准的 Figma 视觉层级。

## 品牌和可访问性

设计色由 Figma Contract Tokens 和 `apps/miniprogram-cq-talent/styles/tokens.wxss` 共同校验；当前代码基准 `#A80F1B`、按压色 `#7F0B14`、柔和底色 `#FCEEEF`。不要再使用 `#E60012` 的旧版本作为新页面基线。默认以 WCAG AA 可读性为目标，状态必须同时有文字，不只依靠颜色。

本文件保留产品约束；具体请求、字段、状态从 [API 契约](api/README.md) 判定；视觉从 [视觉规范](visual-fidelity.md) 判定。
