# MVP 范围说明

## 产品定位

这个 MVP 不是先做一个完整的招生、缴费、媒体和 AI 平台，而是先做好青训俱乐部最核心的训练交付闭环：

1. 管理球队、学员、家长、教练的日程安排。
2. 把细化训练内容组合成标准化训练课程，并关联培养目标。
3. 持续跟踪和评测球员各项能力，形成成长数据。

第一版的目标是证明俱乐部可以稳定管理训练过程，并沉淀可信的球员成长数据。支付、CRM、公众号、抖音、视频号、小红书、AI 视频剪辑、场地评价和赛事系统都放到后续阶段。

## 核心角色

| 角色 | MVP 职责 |
| --- | --- |
| 管理员 | 管理球队、学员、家长、教练、日程、训练内容和评测模板。 |
| 教练 | 查看日程，准备课程，记录考勤，完成课后记录，评测球员。 |
| 家长 | 查看孩子日程、训练重点、出勤记录和能力进展。 |
| 学员 | MVP 阶段不需要独立登录，学员数据由家长和教练侧承载。 |

## MVP 核心模块

### 1. 球队、学员、家长、教练的日程安排

目标：每一节训练课都能明确回答：哪个球队、什么时间、什么地点、哪个教练、哪些学员参加、最后出勤结果如何。

必备能力：

- 管理球队，支持年龄段、水平层级、默认教练等信息。
- 管理学员，并把每个学员绑定到一个或多个家长。
- 把学员和教练分配到球队。
- 创建单次或周期性训练日程。
- 按球队、教练、学员、家长查看日程。
- 记录每节课的出勤状态：到课、缺勤、请假、迟到、特殊说明。
- 支持基础日程变更：取消、改期、更换教练、更换地点。

MVP 页面：

- 管理端日程日历
- 教练周日程
- 家长孩子日程
- 球队训练列表
- 训练详情与考勤页

关键原则：

- 日程是系统的业务骨架。训练计划、出勤记录和球员评测，优先关联到具体训练日程上。

### 2. 训练内容课程化与培养目标管理

目标：让训练交付可以复用、对比和追踪，而不是只依赖教练自由发挥或课后文字描述。

训练内容层级：

1. 培养维度：技术、身体、战术、心理、团队协作等大类。
2. 训练目标：具体目标，例如第一脚触球、传球准确性、1v1 防守、速度、观察扫描、射门终结。
3. 训练练习：可复用的训练动作或组织方式，包括时长、器材、人数、场地布置、指导要点和难度。
4. 课程计划：由多个训练练习组合成的一节完整训练课。
5. 实际训练：某个球队在某个时间真正执行的一节课。

建议课程结构：

| 课程环节 | 示例 |
| --- | --- |
| 热身 | 灵活性、球感、协调性 |
| 技术练习 | 传接球、带球、射门、防守 |
| 战术练习 | 1v1、2v2、抢圈、逼抢、攻防转换 |
| 比赛场景 | 小场比赛、限制条件比赛 |
| 复盘 | 教练总结、个人重点提醒 |

必备能力：

- 创建和管理培养维度。
- 创建和管理训练目标。
- 创建训练练习库，并用年龄段、水平、目标、时长、器材等标签分类。
- 从训练练习库中组合一节课程计划。
- 把课程计划关联到实际训练日程。
- 课后记录实际完成情况。
- 每节课可以关联一个或多个培养目标。

MVP 页面：

- 培养维度与训练目标库
- 训练练习库
- 课程计划编辑器
- 训练日程中的课程计划
- 教练课后完成记录

关键原则：

- 一节课不能只叫“足球训练课”。系统需要记录这节课练了什么、为什么练、哪些人参加、应该观察哪些能力变化。

### 3. 球员能力跟踪与评测

目标：建立家长看得懂、教练用得上的球员成长档案。

MVP 评测维度：

| 维度 | 示例指标 |
| --- | --- |
| 技术能力 | 第一脚触球、传球、带球、射门、防守、弱势脚 |
| 身体能力 | 速度、敏捷、平衡、耐力、协调性 |
| 战术理解 | 站位、决策、观察扫描、无球跑动 |
| 心理表现 | 专注、自信、抗压、纪律性 |
| 团队协作 | 沟通、配合、训练态度 |

评测方式：

- MVP 使用 1-5 分评分，避免一开始做过重的专业量化。
- 每个维度允许教练填写简短评语。
- 记录评测日期、评测教练、所属球队、关联训练日程。
- 展示基准分、最新分、趋势和历史记录。
- 支持给单个球员设置阶段性培养目标。

必备能力：

- 按年龄段或球队水平配置评测模板。
- 教练定期录入球员评测。
- 教练在课后记录轻量观察。
- 按球员和能力维度查看进展。
- 生成简洁的家长侧成长摘要。

MVP 页面：

- 球员档案
- 能力评分表或雷达图
- 评测录入表
- 评测历史
- 家长成长摘要

关键原则：

- 第一版不要假装 AI 已经客观测量了运动表现。MVP 阶段的数据应以教练确认的评测为准，AI 后续可以用于报告初稿、视频分析和训练建议生成。

## 核心业务流程

### 流程 1：创建球队并安排训练

1. 管理员创建球队，填写年龄段、水平、默认教练和默认训练地点。
2. 管理员添加学员并绑定家长。
3. 管理员为球队创建周期性训练日程。
4. 教练和家长可以看到对应日程。

### 流程 2：准备并完成一节训练课

1. 管理员或教练为训练日程选择课程计划。
2. 教练课前查看训练目标和练习安排。
3. 教练课中或课后记录出勤。
4. 教练标记实际完成的训练内容并填写课后记录。
5. 训练数据进入球队训练历史。

### 流程 3：评测球员成长

1. 管理员为年龄段或水平层级配置评测模板。
2. 教练定期对球员进行能力评测。
3. 每次评测保存为历史记录。
4. 家长查看简化后的成长进展。
5. 教练根据薄弱项调整后续训练目标。

## 核心数据模型

| 实体 | 用途 |
| --- | --- |
| User | 登录账号与角色身份。 |
| Parent | 家长资料与联系方式。 |
| Student | 球员档案、年龄段、水平和家长绑定关系。 |
| Coach | 教练资料、专长和球队分配。 |
| Team | 训练球队或梯队。 |
| TeamMember | 学员与球队的成员关系。 |
| CoachAssignment | 教练与球队或训练日程的分配关系。 |
| TrainingLocation | 训练地点基础信息。 |
| TrainingSession | 训练日程，包含球队、时间、地点、教练和状态。 |
| Attendance | 学员在某节训练中的出勤结果。 |
| DevelopmentDimension | 技术、身体、战术等培养大类。 |
| TrainingObjective | 某个培养维度下的具体训练目标。 |
| TrainingDrill | 可复用训练练习。 |
| SessionPlan | 由多个训练练习组成的课程计划。 |
| SessionPlanBlock | 课程计划中的单个训练环节。 |
| SessionDelivery | 实际训练完成记录。 |
| AssessmentTemplate | 按年龄段或水平配置的评测模板。 |
| AssessmentMetric | 评测模板中的具体能力指标。 |
| PlayerAssessment | 某个球员在某个时间点的一次评测。 |
| AssessmentScore | 单个评测指标的分数和评语。 |
| PlayerDevelopmentGoal | 球员个人阶段性培养目标。 |

## MVP 边界

本期包含：

- 球队、学员、家长、教练管理。
- 球队日程与个人日程。
- 训练考勤。
- 培养维度、训练目标和训练练习库。
- 课程计划组合。
- 教练课后记录。
- 球员能力评测。
- 家长侧成长摘要。

本期不做：

- 支付和课包消课。
- CRM 和线索转化。
- 公众号、视频号、抖音、小红书内容发布。
- AI 视频剪辑。
- 计算机视觉自动评分。
- 场地评分和维护流程。
- 赛事管理。
- 装备销售。
- 复杂通知和企业微信集成。

## 验收标准

MVP 完成时应该做到：

- 管理员可以创建球队、绑定学员和家长、分配教练、安排训练日程。
- 教练可以打开今日课程，看到球队名单、训练计划，完成考勤和课后记录。
- 家长可以查看孩子接下来的训练、历史出勤和基础成长摘要。
- 教练可以录入球员能力评测，并查看历史变化。
- 训练历史可以回答：谁在什么时候、跟哪个教练、练了什么、关联了哪些培养目标。
- 球员历史可以回答：哪些能力在提升、哪些能力需要加强、下一阶段训练重点是什么。

## 后续叙事预留

MVP 不实现这些能力，但数据结构要为它们留出口：

- AI 根据出勤、训练内容和评测数据生成教练报告初稿。
- AI 辅助视频打点和精彩片段剪辑，并关联到训练日程。
- 精英球员档案，包含认证评测、比赛视频、发展计划和展示页。
- 场地质量记录，关联训练体验和安全反馈。
- 公众号、视频号、抖音、小红书的内容分发，基于系统内已有训练和比赛素材生成。
