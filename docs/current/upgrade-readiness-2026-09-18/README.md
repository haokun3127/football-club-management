## 已发现的高优先级差距
- 旧“点名扣课确认”与新“日期过后默认计课次、双方直接修正”存在业务冲突；必须从外部课包及财务账中隔离。
- 测评当前限制在周期内编辑，只接受部分标准评分类型，且发布时刻被写作 assessedAt；须支持周期后补录、原始单位和真实课程发生时间。
- 小程序 develop / trial / release 全部指向生产 API；联调环境隔离必须早于任何测试写入。
- 现有独立后台应用未发现；现有 Excel、领域模型图和权限基础应复用，不能把已有后端能力全部重写。
