3. P27/P28保留原咨询设计，先消除重叠；不能认定缺页或重建咨询管线。
4. P23已有4/4选择和排序说明；补排序操作可识别性和P22入口，不新造任意数量快捷入口。
5. 场地筛选、空结果、无定位、比赛赛前/赛后/取消已有状态，优先保留。新增重点是活动上下文、返回来源与数据有效性。

### 5.1 布局落图约束

- P01保留既有四入口与下一次训练；身份区右上头像，训练统计与成果区分开，成果多时只滚动成果卡；图片Banner按后台素材比例裁切，不把标题强行烘焙成业务字段。
- P02顶部头像选择后是周/月日历，再是选中日安排；月格展示有限色块和“+N”，点开当日完整列表；选中日期色与事件类型色分开。
- P08依次为紧凑单孩身份、指标选择/当前层级、雷达及数值、时间范围和单项趋势、关联训练次数、最新评价和最近测试。无足够轴数时用已确认的列表/条形承接，不画失真的两轴雷达。
- P03/P07/P09/P12等数据详情不重复首页大身份卡；标题附近放孩子和来源，内容按实际长度自适应。P16/P18/P25/P26减少固定高空卡；主按钮和底部安全区留出可滚动空间。
- 需要提交才有固定主要提交动作；普通阅读页是否保留底部大“返回”，按返回可发现性与有效信息面积逐页验证，不机械批量删除。
- 保持现有4项底部导航、品牌和组件体系。本轮不重新选择设计风格，不改变已确认的功能图标。

### 5.2 必需的新增状态，优先复用现有页面

P02整月/事件溢出/多孩；P04无可选课及选课；P03取消/已请假/历史；P06版本冲突及失败；P09综合构成/原子/指定历史/缺测或缺规则；P12关联指标筛选；P14达成依据及空；P08评价历史；P18服务说明；绿色其他活动详情。复用X类失败/无权/空态，但必须标明回到哪个孩子和对象。无需将每种状态扩展成独立一级页面。

## 6. 开发需要接住的最小数据契约

以下为**增量契约建议，不是现有接口已支持的声明**。已有后端复用依据见16号第0节；本轮未重跑测试。客户端继续复用app-client BFF，后台复用既有领域及应用服务，不由前端自行计算权威成绩或发放里程碑。

| 对象/用途 | 必须传递的事实 | 复用与增量 |
| --- | --- | --- |
| 页面上下文 | `studentId`、具体`eventId`/记录ID；时间范围、指标路径、筛选、来源页 | 已有绑定与对象授权；路由恢复筛选，服务端仍逐对象校验，不相信前端带来的孩子ID |
| 课程与个人记录 | 活动类型/状态/时间/场地、参与孩子；当前有效计次、来源、版本、修改历史 | 复用课程和事务；新版培训计次与后台财务账本隔离；提交用已有版本保护与幂等语义 |
| 测评事实 | 原始项目和值/单位；所选课程与课程日期；整数分值/等级及映射版本；确认、修订与缺失原因 | 复用 `assessment-workflow`、指标图和版本血缘；补两段区间、逐项课程归属，不重建发布工作流 |
| 雷达/趋势 | 指标ID及子指标、可比尺度、每轴取值日期/来源、时间窗、版本可比状态 | 复用模型关系；跨不同单位先按已发布规则映射；未配置、未测、不可比显式返回而非0 |
| 关联训练 | 指标到训练内容关联、相同时间窗、有效课程记录与去重数量 | 沿既有训练内容关联增量补查询；不把一次课中的多个内容重复累计成多堂课 |
| 里程碑 | 规则ID/版本、适用对象、条件、徽章/文案、达成时间、来源事实ID、当前有效状态 | 新增规则及达成记录能力；以课堂/已确认测评触发；更正处理须明确后再实现，客户端不自行授予 |
| 场地与活动位置 | 场馆ID/名称/地址/有效坐标，独立的本次集合时间/集合点 | 复用现有对象，补后台维护和持久化；场馆默认信息不能覆盖本次安排 |
| 内容/咨询/消息 | Banner图片与类型化目标；服务/咨询ID、孩子和可见进度；消息目标及最新事实 | 复用现有咨询链和内容基础；目标不存在/失效可恢复，内部备注不进入家长响应 |

接口实现时应对照既有 `packages/domain/src/metric-graph-services.ts`、`apps/api/src/application/assessment-workflow.ts`、`apps/api/src/persistence/training-session-repository.ts` 等位置，使用现有命名与仓储；表中字段是语义要求，不要求照字面新造一套ID或表。

### 6.1 仍需细化的规则与安全退路

- 正式评分阈值、适用年龄/组别、里程碑条件及更正后的授予处理仍未定；画图可用明确标注的演示数据，但开发验收不能当正式标准。
- 雷达默认指标组由后台维护；建议每轴取所选时间范围内最新已确认可比结果，并显示各轴实际日期。**具体取值策略仍是候选，不将此建议自动写成已确认规则。**
- 里程碑更正后自动撤回、保留历史获奖或重新判断等策略尚待决定；先设计“规则/来源异常”的可解释状态，不默默保留错误奖励。
- 请假时间边界、取消后恢复、特殊课程测评归属等按既有O项处理；未确定前给明确不可操作原因并保留输入，不能擅自变更用户已定的双方直接修正原则。
- 上述待决只阻挡依赖它的分支，不阻挡画板重叠修复、身份/入口、已确认首页日程布局和既有页面整理。
