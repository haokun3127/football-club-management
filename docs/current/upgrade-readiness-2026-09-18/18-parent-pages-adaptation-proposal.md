## 2. 先统一四条跨页面规则

### 2.1 孩子上下文按页面职责区分

首页、成长、训练记录、测评详情、报告、里程碑、个人档案始终属于一个孩子；首页与成长沿用已确认的头像切换方式。日程支持全部/单孩。我的、消息中心、我的咨询属于家长账号，可以列出多个孩子的对象，但每条标明归属，进入详情后明确具体孩子。俱乐部动态、服务和场地目录属于公共内容，无需强行重复孩子选择器。

从某孩子记录进入的详情继承该孩子；从全部日程进入共享活动先显示参与孩子，进行请假/修正等个人动作时明确选择操作对象。编辑表单不允许顶部切换悄悄换掉提交对象。深链从消息进入时应同时校验孩子与对象，不能沿用错误的全局上次选择。

### 2.2 布局按用途复用，避免所有页面都堆同样大卡片

- 详情：标题及状态 → 孩子/对象 → 时间地点或成绩关键值 → 内容及历史 → 相关操作。
- 列表：紧凑对象与筛选 → 摘要（确有意义时）→ 日期分组或条目；日期、状态、核心数字不藏进详情。
- 表单：对象摘要 → 必填/可选输入 → 影响说明 → 一个主要提交动作；输入失败原地恢复。
- 成功页：结果 → 对象 → 下一步，不另造必须逐个经过的成功页链；可复用既有 P05/P20。
- 公共内容：封面/正文按内容长度排版，减少无意义卡片嵌套；长姓名、地址和项目名允许换行。

沿用项目现有视觉语言及设计候选尺寸，不换主题。事件类型严格训练蓝、比赛红、其他绿，状态另配文字；不因品牌红色就把所有训练事件画红。主操作与事件色块使用不同层次。个人数据页显示身份但不每页重复首页的大型球员卡。

### 2.3 成绩、训练与里程碑共用事实

成绩保留原始值/单位、整数分值、等级的区别；缺配置显示缺配置，不补零。日期为项目关联课程日期，修订和确认时间另解释。一个测评批次可来自多堂课，不虚构整批共同发生日期。

课堂统计是有效培训记录及内容关联，不等于实测动作次数；相关训练次数与成绩变化并列显示不代表因果已被证明。里程碑只来自后台规则与达成记录，不能把每条评价更新自动变成奖章。旧结果更正不能在历史中伪装成新训练或新测试。

### 2.4 入口与返回保持连续

优先复用 P03/P07/P09/P12/P14/P30 等详情和列表模板，不为每个入口复制一套事实页。返回恢复孩子、日期/时间范围、指标层级、筛选和滚动位置；提交成功使来源页显示最新结果。首页四个图标的外观和数量保持用户已确认要求；本轮只补清楚其去向及设置入口。

### 4.2 优先复用状态，不按数量增建页面

1. **其他活动详情（需补承接）**：沿用活动详情模板，绿色类型标识，显示活动目的、时间、集合地点、注意事项、对应孩子及最终状态；不默认显示训练计次或比赛比分。现有历史路由清单明确该承接尚需补齐，最终画板编号确认后分配。
2. **首页请假选课（P04 内选择态）**：当前单孩下选择课程，展示日期时间地点；没有可选课就说明原因，不将“最近一堂”悄悄提交。
3. **指标构成/历史测量（P09 变体）**：承接 P08 雷达图下钻、单项趋势和某次原始事实；一个模板按数据类型变化，不另造与成长页不同的计算模型。
4. **关联训练（P12 筛选态）**：显示孩子、指标、时间范围及相关内容，能逐堂回查。
5. **里程碑依据（P14 展开或详情态）**：展示达成时间、条件、实际结果和来源；分享继续使用同一成果对象。
6. **教练评价历史（候选复用成长页展开态）**：P08最新评价可查看家长可见的历史与作者日期，沿用一份当前评价及修订，不把同一教练评价复制到多个独立编辑对象。暂无独立家长页面编号，不扩大为新的一级导航。
7. **服务说明与教练说明（P18/P25 内容态）**：保证“了解/查看详情”有真实内容，介绍不足时用同页展开，不为页面数量空建详情。

共同 X01—X15 中，登录/身份/绑定、加载/空/失败/无权、冲突/保存失败、取消、分享授权和窄屏大字状态按家长流程承接；X16为后台登录，不在本轮范围。X08的草稿表示本地待保存时，不能宣称请假或课次修正已在服务器生效。

## 6. 布局落图时的验收目标（本轮未执行）

- 首屏可以识别当前对象、状态与关键时间/成绩；无需先滚过大幅重复身份卡。
- 动作位置按业务状态变化：取消课程不突出请假或出发，未测不显示能力为零，暂无里程碑不伪造祝贺。
- 下级页面有清楚的返回层级，只有一级页面承担底部主导航；若现有原型的底栏不同，先实读再调整，不能批量机械删除。
- 长项目名、孩子姓名、地址和140%大字情况下不遮住操作；沿用已有320/375/430宽度检查约定，具体视觉尺寸待实图验证。
- 色彩之外有文字信息；事件分类色不吞掉取消/改期/错误状态。图表提供数值信息，不以图形面积替代可读数据。
- 关键提交显示保存中、成功、失败；失败保留输入，重试不重复生成业务事实。空结果与加载失败区分。
- 演示姓名/日期/成绩只用于设计场景；不将设计示例阈值写入正式规则。
