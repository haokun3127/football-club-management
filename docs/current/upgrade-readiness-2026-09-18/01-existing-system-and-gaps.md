## 审查方法和基线
读取产品 v1.1 六份文档、实际 package scripts、56条小程序路由、主题变量、app-client关键路径、assessment-workflow、SQLite迁移入口、认证和Excel读取。保留当前用户改动，未改产品源码。

“已有基础”只证明对应代码或文件存在，不等于所有新业务要求已实现。以下将已复核的冲突和后续实现候选分开，避免把未经逐接口测试的能力记成已通过或完全缺失。
