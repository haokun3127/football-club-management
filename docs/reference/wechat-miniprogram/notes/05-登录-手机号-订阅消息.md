# 05 登录、手机号、订阅消息

出处：`pages/open-login.md`、`pages/server-code2session.md`、`pages/open-getphonenumber.md`、`pages/subscribe-message.md`、`pages/ability-network.md`

## 登录链路 `[官方]`

1. 小程序：`wx.login()` 拿 **code**（本项目 `pages/login/index.ts` 已在用，并把 code 作为页面 query 传递/刷新）。
2. 服务端：用 code 调 `code2Session`（`https://api.weixin.qq.com/sns/jscode2session`）换 `openid` / `session_key` / `unionid`。
3. 自定义登录态：`session_key` **不下发前端**；服务端签发自己的 token（本项目 `utils/auth.ts` + `utils/store.ts` 的模式）。

硬约束 `[官方]`：

- **`api.weixin.qq.com` 不能配置为小程序服务器域名，也不能在小程序内直接调用**；`AppSecret` 只能留在服务端（本项目正是这个拓扑：小程序 → `https://cqtc.pomi.tech` → 微信 OpenAPI）。
- code 只能换一次、有效期短；本项目若在 query 里传 code，需要确保不被复用/缓存到下一次登录（现有 `phoneAuthorizationReserved` / callbackConsumed 防护只覆盖手机号回调）。
- 服务端域名必须是 **HTTPS + ICP 备案**，且不能是 IP/localhost；「不支持配置父域名而使用子域名」这条要特别小心（配 `pomi.tech` 不能覆盖 `cqtc.pomi.tech`，反之亦然）。域名类改动只能在小程序后台做，代码侧无法验证。

## 手机号快速验证（本项目登录页正在用）`[官方]`

- 组件：`<button open-type="getPhoneNumber" bindgetphonenumber="...">`；回调 `event.detail.code` 交给服务端换手机号。
- **这是付费能力**：自 2023-08-28 起，**每次调用成功收费 0.03 元**。
  - 每个小程序账号有 **1000 次免费体验额度**（正式版/体验版/开发版**共用**，超出后体验版与开发版同样收费）。
  - **扣费节点 = 收到 `bindgetphonenumber` 的 success 回调时**（不是用户点击时、不是你换手机号成功时）。
  - 免费主体（本项目不在其中，足球俱乐部属民办体育培训）：政府、非营利组织；事业单位且类目为政务民生；公立医疗机构、学历教育（学校）。
  - 资源包按到期时间顺序划扣；未使用可在支付后 7 天内退款；对调用量有疑问按官方《手机号计费误差问题排查指南》排查。
- 与隐私的耦合：手机号同时是隐私接口，**必须先完成 `04` 里的声明与同意同步**，否则组件不可用。
- 频次限制：客户端会在「授权过于频繁」时直接失败——本项目已处理 `too frequently` 分支（`pages/login/index.ts`），这是正确的既有经验，保留。

## 订阅消息（家长端提醒功能相关）`[官方]`

- 三类：**一次性订阅**、**长期订阅**、**设备订阅**。小程序侧用 `wx.requestSubscribeMessage`（一次性/长期）或 `wx.requestSubscribeDeviceMessage`（设备）。
- 模板必须先到公众平台配置并审核通过，拿到模板 ID；不能自定义文案。
- 服务端下发：`subscribeMessage.send`；**下发上限：开通支付能力 3000 万/日，未开通 1000 万/日**。
- 用户勾选「总是保持以上选择，不再询问」后，`wx.requestSubscribeMessage` **不再弹窗**，沿用上次选择；用户要改只能去小程序设置里改（产品文案不能承诺「一定会弹窗」）。
- 事件推送（推到消息推送配置的服务器地址）：
  - `subscribe_msg_popup_event`：用户在弹框里的选择（`SubscribeStatusString` = accept/reject）；
  - `subscribe_msg_change_event`：用户在服务通知里「拒收」；
  - `subscribe_msg_sent_event`：下发结果（含 `ErrorCode` / `ErrorStatus`）。
- 实践含义：**「家长点了同意」不等于「消息已送达」**，要按事件分别落库，并在拒收后停止发送、在页面上如实提示。

1. 在发布文档与成本核算里写明手机号能力是**按次计费**的：算清「新用户登录 / 老用户重新授权」的调用量，并在后台确认体验额度与资源包余额。`[本项目]`
2. 检查 `pages/login/index.ts` 里 code 的获取与消费是否只消费一次（code 复用会直接登录失败）。`[本项目]`
3. 家长端提醒若依赖订阅消息：先确认模板是否已配置并审核通过、服务端消息推送地址是否配置，再评估「一次性/长期」的合规用法（一次性订阅一次授权只能发一条）。`[官方]`
4. 服务器域名（`cqtc.pomi.tech`）在后台确认属于「服务器域名」且证书/备案有效；`setting.urlCheck: false` 不能作为跳过该验证的理由。`[官方]`
