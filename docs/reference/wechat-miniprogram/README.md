# 微信小程序官方规范参考（腾讯官方正文留档）

本目录是**腾讯官方《微信开放文档》正文的本地留档 + 面向本项目的提炼**，用于在开发/评审/发布过程中随时核对最新平台规范，避免按记忆或旧习惯写出与当前平台不一致的代码、配置和流程。

可执行规则见 `.trellis/spec/miniprogram/frontend/`；本目录继续作为平台事实证据，不直接承担工程门禁。

- 抓取日期：2026-09-18（正文取自 `developers.weixin.qq.com` 服务端渲染页面）
- 覆盖：46 篇官方页面正文（框架、配置、分包、能力限制、隐私合规、开放能力、性能、审核与运营、设计）
- 平台最新基础库（抓取时点）：**v3.17.3（2026-08-20）**
- 可复现：`python3 scripts/wechat-docs/fetch-official-docs.py`（清单在 `scripts/wechat-docs/sources.json`）

## 目录结构

```
docs/reference/wechat-miniprogram/
├── README.md            ← 本文件：索引 + 阅读规则
├── manifest.json        ← 每篇的 URL / HTTP / 字节数 / SHA-256 / 标题（可核对）
├── notes/               ← 面向本项目的提炼（先读这里）
├── pages/               ← 46 篇官方正文（Markdown，原文留档，出处分节引用）
└── _raw-html/           ← 原始 HTML 留证（本地，不入 git）
```

## 阅读规则（给 AI agent 和开发者）

1. 动小程序代码前，先读对应主题的 `notes/`；`notes/` 只给**结论 + 出处行号级链接**，细则回 `pages/` 原文。
2. 涉及版本/限制/接口可用性的判断，**只以本目录 `pages/` 正文和平台后台实际配置为准**，不要用记忆、旧交接文档或本 README 的摘要下结论。
3. 规范会变。本目录是 2026-09-18 的快照，**超过约 1 个月或发布新版本前重跑抓取脚本**，`manifest.json` 里的 SHA-256 能直接看出哪些页面变了。
4. 结论分两类标注：`[官方]` = 官方正文原话，`[本项目]` = 对本仓库现状的探测结果（含文件路径）。

## 已知留档限制

- **基础库版本分布表抓不到**：`pages/client-lib-version.md` 的表格由前端脚本填充，留档只有表头。要看真实分布请用小程序后台或开发者工具（不要用本文档推测占比）。
- **平台后台状态无法从代码验证**：服务器域名、业务域名、隐私保护指引、手机号付费额度都在微信公众平台后台，本地只能核对代码与配置，后台项需人工在后台确认。
- **`_raw-html/`** 是本机留证（未入 git），若目录被清理，重跑抓取脚本即可恢复；`manifest.json` 的 SHA-256 可用于判断前后是否一致。
