# 小程序开发指南

小程序提供了一个简单、高效的应用开发框架和丰富的组件及API，帮助开发者在微信中开发具有原生 APP 体验的服务。

本章分主题的介绍了小程序的开发语言、框架、能力、调试、云开发等内容，帮助开发者快速全面的了解小程序开发的方方面面。
