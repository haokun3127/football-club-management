# Football Club Management

New project workspace for a football club management application.

## 开发

```bash
pnpm install
pnpm check
pnpm dev:api
```

API 默认运行在 `http://127.0.0.1:3000`。

## Git

This repository uses Git for source control. Keep generated files, dependency folders, local databases, and environment secrets out of version control.
