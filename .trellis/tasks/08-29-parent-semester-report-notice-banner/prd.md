# 家长端学期成长报告与首页通知 Banner

## 目标

补齐家长端两个甲方要求：从“我的孩子”进入可查看当前学员的成长报告；日程首页展示俱乐部运营通知 Banner。两项都必须消费真实俱乐部数据，不把 Figma 示例文案、日期、分数或名单当作运行数据。

## 功能要求

1. 新增全屏 `pages/parent/semester-report`，支持返回、当前绑定学员切换和最近一个可用阶段选择。
2. 报告由现有真实 `growth-summary`、家长日程和比赛记录组成：展示能力维度、训练/比赛摘要、出勤摘要、数据更新时间；没有真实评语时展示“暂无教练评语”，不得生成伪造评语。
3. “我的孩子”页的“成长报告”入口跳转到报告页；成长页现有雷达和训练历程入口不改变。
4. 日程首页展示真实俱乐部 Banner；Banner 至少包含标题、摘要、发布日期/有效期和可选详情入口。没有 Banner 时不显示伪通知，月历布局保持稳定。
5. Banner 数据通过现有内容 BFF 的 `content/articles` 扩展 `category: "notice"`，不新增伪 API；客户端在 TS 中预计算展示字段。
6. 所有页面保持 WXML 无 `.map()`、`.filter()`、`.slice()`、`.indexOf()` 等 JS 方法调用。
