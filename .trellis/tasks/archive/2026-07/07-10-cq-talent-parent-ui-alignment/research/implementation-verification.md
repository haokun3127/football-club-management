# 家长端 UI-2 实施与验证记录

日期：2026-07-11

## 已实现

- 家庭日程默认全部孩子，孩子选择横向滚动，日期范围修正为 7 天，活动卡统一业务状态与时间格式。
- 同一活动详情路由按训练、比赛、其他活动生成三种视觉和信息结构。
- 成长页的雷达点、指标列表、页内摘要和独立详情共用同一个 `metricId`；旧请求晚返回时只写缓存，不覆盖当前选择。
- 指标详情展示真实记录时间轴、变化、同龄平均和来源活动。
- 我的孩子页面只展示真实档案、课时、保险和俱乐部服务；移除未闭环私教提交和账号绑定占位入口。
- 200 人验收种子补齐课时台账和保险保单；家长活动详情在 API 层裁剪为当前家庭孩子，避免球队名单泄露。
- 指标详情将内部单位转为中文展示、过滤公式/权重文案，并按活动去重来源。
- 新增 `utils/presentation.ts` 统一活动状态、日期、时间范围和家庭参与者文案，并增加单元测试。
