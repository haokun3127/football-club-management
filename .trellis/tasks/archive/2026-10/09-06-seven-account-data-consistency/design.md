# Design

Fix the canonical importer's positive-credit rule. Add a separate explicitly
backup-attested repair function for the seven fixed demo scopes, not a startup seed.
This authorized reset can replace their inconsistent credit histories, normalize
activity status and linked records and add date-keyed schedules. Preserve identities,
catalogs and all unrelated rows. Use one transaction and an integrity-checked backup.
Rehearse on a production snapshot before the live write; restart API for readback.
