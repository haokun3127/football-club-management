# 网页管理后台及所需 API 完善

## 目标与用户价值
让俱乐部运营和教学管理通过网页完成已确认的管理业务，使用成熟框架项目承接常见后台交互，接入共同业务事实。完成指真实操作、保存回读、权限和验收通过。

## 授权与事实
- 2026-10-10 用户明确允许创建任务并规划，范围为网页管理后台及其所需 API，偏好现成框架。
- 现有 Fastify、SQLite 和 domain 业务层继续承载业务；apps/api/backoffice/app.js:1 目前是原生浏览器客户端。
- apps/api/src/routes/backoffice.routes.ts:9 提供密码登录、会话和退出；backoffice-web.routes.ts:35 提供五类只读目录；并无完整编辑界面。
- .trellis/spec/api/backend/backoffice-authentication.md 为现有浏览器安全契约；不能用微信会话或调试身份替代。
- 原始工作区有 282 项未提交改动；研究目录保存实施前路径快照，原有改动不能擅自回退或包含进提交。

## 边界
不增加在线支付、分账、自动投保、复杂审批、任意文件自动理解、复杂 BI 设计器、跨俱乐部外部服务或外部通知渠道。O-04 正式评分阈值无来源时仅支持可配置草稿和试算，不发布演示标准；O-05 客户表格未知时提供标准模板；O-12/O-13/O-14 未定流程保持明确限制。数据库维持 SQLite 单写部署。生产发布与真实账号供应单独检查现有授权，不能把本地结果称为上线验收。
