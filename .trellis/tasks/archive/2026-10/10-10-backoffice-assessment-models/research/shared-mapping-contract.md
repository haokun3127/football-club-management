# Implementation findings
The existing domain supports typed raw facts and standardized graph inputs, but there was no versioned raw-to-integer/grade mapping. Existing assessment workflow accepts standard scores only; published raw results and scores remain canonical facts. New domain score-mapping functions validate finite bounded intervals, own exact boundaries, treat score-grade domains as integers, reject unit conversions, and have synthetic tests. Migration 0033 stores version definitions by club/test item and stage. Browser draft editing and trial never publish player facts. A publish action requires official basis/reference and a valid complete mapping; active/archived definitions are immutable. These definitions still need explicit immutable template bindings and result lineage before formal use; do not claim mapping trials are integrated player results.
Data dependency: shared people/activity/plan CRUD is stable and 28 affected tests passed; remaining content settings and complete data-stage gate remain open for final integration.
