# C12 design

The page stays within existing client contracts: a coach event workbench validates a real accessible event, supplies its roster and is the sole page-level source of its normalized `assessmentTemplateId`; only then may C12 request the matching form. The form must echo that exact `templateId` and provide a nonempty `templateVersionId`. C12 performs no URL, first-list or name-heuristic selection; the existing shared API normalization is outside this page-only batch. This makes no claim that the backend has a separately persisted event-template relation. Local draft state is presentation state only; the established assessment write remains the only write path. A missing role/event, route/workbench mismatch, cancelled event, absent workbench template/form/version or template-id mismatch leaves the page non-writable.

The Figma authority is `93:1030`; node `231:108` clarifies the whole-team entry flow. A submission clears only rows with confirmed success. Failed or network-unknown rows remain in local draft and are not automatically retried, because the current request layer creates a new idempotency key per request. This batch does not introduce task creation, bulk server submission, new API types, or synthetic results.
