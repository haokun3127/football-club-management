# Design: Coach C1-C3 Figma Restoration

The three pages share the coach workbench language but remain page-owned to avoid changing unrelated coach flows. C1 establishes the schedule header, week strip, summary card, activity row, and selected tab. C2 uses a compact custom header, an in-progress event card, attendance summary, progress list, and a three-action grid. C3 uses the same top-safe-area geometry but forms are stacked in separated white cards with a single red submit affordance.

The runtime date and event values stay live. Text may differ from the Figma sample, but the width constraints must preserve status/action controls and never overlap the system capsule. The bottom tab bar follows the existing shared visual language only after matching the C1-C3 Figma measurements.
