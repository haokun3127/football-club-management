# C16 design

Identity comes only from the authenticated coach session (safe fallback “教练”); home coach-name fields cannot override it. Recent teams come from one range `today-29..today` with a frozen local clock in regression tests, so copy cannot imply permanent appointment or season membership. A request sequence id protects both stale success/failure. Fixed safe error text never displays raw upstream errors. Logout is page-level single-flight after confirmation; menu routes remain account, permissions, private-interest and help.
