# 重庆天才家长端Figma全页面对齐

## Goal

基于 UI-1 共享组件和完整 Figma 文件，完成家长端五个现有路由的全部状态设计与实现：家庭日程、三类活动详情、成长/雷达、指标详情和我的孩子；保留双孩家庭默认全部孩子、隐私裁剪和真实 metricId 下钻。

## Requirements

- UI-1 必须先完成；家长页不得复制另一套 token/header/tab/status/card。
- `parent/schedule` 适配 P1/P1.1：默认全部孩子、紧凑孩子选择、周条/数量、类型筛选、彩色类型边、取消/变更状态和家庭参与者。
- `parent/event` 保留统一路由，按 training/match/other 输出三种视觉结构；训练突出内容/能力/考勤/扣课/总结，比赛突出赛前/比分/事件/孩子表现，其他突出说明/参与/通知。
- `parent/growth` 适配 P4/P5：使用 MetricView、雷达点击和列表点击共享 metricId；缺数据不画 0，不显示其他学员；下方摘要与来源真实。
- `parent/metric` 适配 P6：趋势、最近记录和来源活动；只有真实数据才显示平均/趋势/百分位，不展示公式权重。
- `parent/child` 适配 P7/P7.1：双孩切换、档案、真实课时/保险、俱乐部服务和私教意向；缺账号/内容 BFF 时隐藏假入口或使用业务化状态。
- 清理“提醒待接入、正式登录后、队伍待同步”等技术/占位文案；不可用能力不伪造成可操作。
- 同步完整 Figma 文件的家长 Generated frames，使全部孩子、可下钻雷达和真实登录边界与最终代码一致。

## Acceptance Criteria

- [x] 五个家长路由的 ready/loading/empty/error/pending 状态全部使用 UI-1 组件并通过渲染检查。
- [x] 双孩家长默认看到全部孩子，筛选可恢复；家庭日历和详情不泄露其他 198 名学员。
- [x] 三种活动详情结构明显不同，字段缺失使用业务化说明，不回退通用字段墙。
- [x] 雷达/列表/摘要/详情始终使用同一 metricId；缺数据不造 0 或排名。
- [x] 指标来源可跳转到对应活动详情，权限错误明确且不泄露其他孩子。
- [x] 页面不存在 Figma 假姓名、固定分数、TOP 排名或技术占位文案。
- [x] Figma 家长对应 frames 与最终信息结构同步，逐页 DevTools 截图通过。
- [x] 全量类型检查、测试和家长 smoke 通过。
