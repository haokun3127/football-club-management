# 重庆天才小程序任务工作台与核心交互

## Goal

把重庆天才小程序从活动入口列表提升为俱乐部可试用的任务工作台，修正家庭日程、活动详情、比赛录入、Tab 导航和训练内容编辑中的高风险交互。

## Requirements

- 教练首页支持今日/本周范围、任务概要、状态筛选和按时间排序的活动卡。
- `coach/home` 保持 `date` 兼容，新增 `from/to`，由后端返回权限裁剪后的 summary/tasks/events。
- 活动卡和活动工作台按类型、状态、workflow、capabilities 展示唯一优先主操作。
- 家长日程默认展示全部孩子，允许按单个孩子筛选；大量孩子不得形成标签墙。
- 训练、比赛、其他活动详情使用差异化结构，不展示内部 ID 或技术文案。
- 比赛助攻默认无助攻；比赛类型和事件类型从 capabilities 获取；完赛记录校验对手和比分。
- 自定义 Tab 切换不得累计页面栈。
- 训练管理必须选择明确活动，回填已保存项目，项目树可折叠/搜索，并在保存前显示已选项目。
- 用户界面不得出现 API、BFF、Idempotency-Key、P1/P2 等开发术语。

## Acceptance Criteria

- [x] 全部孩子视图同时显示多孩子活动，单孩子筛选可恢复到全部。
- [x] 教练今日/本周工作台显示统计、筛选和正确的下一步操作。
- [x] 训练活动不显示比赛录入；比赛活动显示比赛任务。
- [x] 训练、比赛、其他活动详情具有不同卡片结构。
- [x] 无助攻进球不会生成任何助攻记录。
- [x] 连续切换 Tab 20 次不增加页面栈。
- [x] 已保存训练项目重新进入仍保持选中，不会无提示覆盖。
- [x] 用户页面静态搜索不包含技术术语。
- [x] API、domain、小程序类型检查和测试通过；200 人 smoke 通过。

## Out of Scope

- 雷达下钻与评测录入重构（后续任务）。
- 微信生产登录与真机验收（后续任务）。
- 战术板、公众号提醒、私教订单、全队排名。
