# C5 销课流程按新版 Figma 落地

## Goal

将教练端销课从单一确认页扩展为可回溯、可纠正的全屏流程，并与在线 Figma 的 C5/C5.1 视觉结构一致。

## Requirements

- 保留现有 C5 活动销课确认能力和真实 API 契约。
- 教练可从销课页进入全屏课时更正页；不得使用弹窗承载主流程。
- 更正页只能展示真实活动参与学员，并通过现有 PATCH lesson-confirmation 接口提交 ±0.5 课时调整。
- 不新增伪造的历史接口、示例手机号、学员数据或 session。
- 现有缺少历史查询接口时，代码只允许复用已有真实活动/销课读取能力，并明确未形成跨活动历史聚合的边界。
- WXML 不调用 map/filter/slice/indexOf 等 JavaScript 方法；显示字段在 TS 预计算。

## Acceptance Criteria

- [ ] C5 在线 Figma 新增的待处理销课画板对应现有教练销课页面文案和结构。
- [ ] C5.1 更正页为全屏页面，具备返回、真实学员列表、调整操作、提交状态和错误状态。
- [ ] 更正提交带幂等键，成功后重新读取并清理已保存的本地调整。
- [ ] 定向 C5 测试、微信小程序 TypeScript 检查、`git diff --check` 通过。
- [ ] 代码和文档使用路径限定提交，不能带入工作区其他未提交文件。
