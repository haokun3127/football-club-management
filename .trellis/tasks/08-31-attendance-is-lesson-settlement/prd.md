# 点名即扣课，移除课时更正流程

## Goal

点名是唯一出勤和扣课动作；停用独立销课、课时更正及其正常导航，保留历史路由兼容。

## Requirements

- 用户已于 2026-08-31 明确确认：点名就是唯一的课时完成动作；课时更正不需要。
- 已到和迟到计为到课并占用一节课；未到不扣课。
- 教练可在训练工作台直接点头像切换“已到/未到”；该操作通过真实出勤接口保存，页面只显示绿色已到和灰色未到，不恢复流程状态、销课或查看详情入口。
- 出勤接口必须以当前整份点名结果原子同步课时账本：同一活动、同一学员至多保留一条 `attendance` 来源扣课；从到课改为未到时撤销这条来源扣课。此为同一项点名的账务同步，不产生用户可见的“课时更正”流程。
- 独立 `lesson-confirmation` 读写接口不再是可用业务入口。旧 POST/PATCH/GET 必须返回明确的弃用错误，不能再产生第二条扣课。
- 教练任务和工作台不再生成或展示 `lesson` / “确认销课”动作。
- 旧小程序路由必须兼容：带活动 ID 的旧销课、课时更正、销课详情跳转至对应点名页；无活动 ID 的旧销课历史跳转至教练日程。不得因旧链接白屏或报错。
- 在线 Figma `zZ6wKyOHKcO4UYXDd9jGwv` 是唯一设计基准。正式 C4 `93:665` 已同步为“点名即扣课”；C5 `537:2`、C5.1 `93:765`、历史 `537:79`、详情 `537:156` 已标注为历史归档，不作为当前交付。
- 不删除历史路由或数据库记录；只撤出正常入口并停止旧写入。WXML 不调用 `.map()`、`.filter()`、`.slice()`、`.indexOf()`；所有暂存必须路径限定，禁止 `git add -A`。
