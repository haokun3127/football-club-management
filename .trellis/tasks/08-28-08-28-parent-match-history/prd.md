# 家长端比赛历史

## 目标

让家长在成长页进入一个全屏的“比赛记录”列表，查看当前选中学员近 180 天内真实比赛，并可进入既有 P2.1 比赛详情。

## 范围

- 仅修改小程序家长端页面与测试、任务文档。
- 数据只来自现有 `getParentCalendar` 日程接口；不得新增伪数据、伪接口或伪比分。
- 只展示当前家长会话选中的学员，不能把其他绑定学员的比赛混入列表。
- 比赛按开始时间倒序展示；每行展示比赛名称、日期时间、球队/场地、比分（有真实比分时）和状态。
- 点击有 `event.id` 的记录进入 `/pages/parent/event/index?id=<event.id>`。
- 无比赛时显示明确空态；加载失败时显示可重试错误态。
- 全屏子页带返回按钮，不使用弹窗。

## 设计依据

- 唯一在线 Figma 文件：`zZ6wKyOHKcO4UYXDd9jGwv`。
- P4.2 Training History：`499:18`，复用其全屏列表、白色卡片和返回顶栏结构。
- P2.1 Match Detail：`93:170`，复用比赛类型、比分和比赛状态语义。
- 当前在线文件没有独立“比赛历史列表”画板，因此本任务的列表属于受约束的组合设计，不能声称是独立画板的逐像素复原。

## 验收标准

1. 测试证明只加载当前学员的比赛，并按日期倒序。
2. 测试证明真实比分字段缺失时显示“比分待同步”，不填入 Figma 示例比分。
3. 测试证明点击比赛行进入既有详情页。
4. 测试证明 WXML 不调用 `.map()`、`.filter()`、`.slice()`、`.indexOf()`。
5. 小程序 TypeScript、定向测试、WXML/WXSS 编译和全仓门禁通过。
6. 取得 WeChatIDE 模拟器真实 375×812 截图，确认首屏导航、列表卡和空态/有数据态布局。
