# 日历下拉箭头与双端月历几何修复

## 目标

让家长端和教练端的周日历→月历入口与在线 Figma 的几何一致：入口位于日期条内部并垂直居中，箭头方向清晰，不被旧定位规则推到日期条下方。

## 范围

- 家长端 `pages/parent/schedule`：修复周条的月历展开入口。
- 教练端 `pages/coach/schedule`：复用同一入口几何，并保留展开月历、切换月份、选日回到日视图的能力。
- 不修改 API、角色会话、生产数据或其他页面。

## 验收标准

- 在线 Figma `zZ6wKyOHKcO4UYXDd9jGwv` 的家长月历折叠/展开节点 `1008:186`、`1008:436` 作为视觉基准；教练 C1 日程节点 `93:578` 作为端内基准。
- 两端折叠入口均位于日期条内部，使用 `top: 50%`、`bottom: auto`、`transform: translateY(-50%)`，不再使用 `bottom: -14rpx`。
- 两端均可展开月历、切换前后月份、选择日期并回到日视图。
- 定向测试、目标 WXML/WXSS 编译、全仓门禁、`git diff --check` 和真实 `375×812` 模拟器截图均通过。

## 约束

- WXML 不使用 `.map()`、`.filter()`、`.slice()`、`.indexOf()` 等 JS 方法。
- 提交必须路径限定，不能带入工作区其他未提交文件。
# 日历下拉箭头与双端月历几何修复

## 目标

让家长端和教练端的周日历→月历入口都与在线 Figma 的几何一致：下拉控件位于周条内部并垂直居中，箭头方向清晰，不因旧 CSS 边框或旋转规则产生歪斜。

## 范围

- 家长端 `pages/parent/schedule`：修复折叠周条的月历展开控件位置和图标样式。
- 教练端 `pages/coach/schedule`：保留已有月历展开、月份切换、选日回到日视图能力，并使用相同的折叠入口几何。
- 家长端 TabBar 继续保持“日程 / 成长 / 发现 / 我的孩子”顺序。
- 不修改 API、角色会话、生产数据或其他页面。

## 验收标准

- 在线 Figma `zZ6wKyOHKcO4UYXDd9jGwv` 的 P1 展开/折叠状态作为视觉基准。
- 折叠状态的下拉控件在周条内部垂直居中，不位于周条下方；展开状态的收起控件方向正确。
- 家长和教练端均可展开月历、切换前后月份、选择日期并回到日视图。
- 定向 Vitest、TypeScript、目标 WXML/WXSS 编译、全仓 `check`、`git diff --check` 和真实 375×812 模拟器截图均通过。
