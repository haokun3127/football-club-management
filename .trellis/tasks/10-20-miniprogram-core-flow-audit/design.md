# 审计方法

1. 固定 Git/版本边界；读取需求、页面路由、当前设计目录。
2. 通过认证 Figma MCP 读取核心节点上下文及截图，保存本轮证据。
3. 微信官方 CLI 读取运行时、截图及日志；有权限的现有身份优先只读。不向远端注入测试身份或写业务数据。
4. 需要写入的流程在可销毁本地数据库/合成数据中验证；无法搭建或无法捕获的步骤登记具体阻塞。渲染替身不得冒称原生模拟器。
5. 静态检查页面到 API/业务服务，定位确定缺陷；用定向现有测试补证，不为只读审计修改源码。
6. 性能区分网络、请求链、重复载入、资源与渲染；测量需带环境、样本和限制。

本任务产物集中 research/ 与 audit-report.md；只有当前状态入口增加链接。无迁移、部署或回滚动作。审计脚本仅限本任务，退出恢复临时运行态。
