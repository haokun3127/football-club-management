# API Backend Directory Structure

The API package lives in `apps/api` and is a Fastify service over `@football-club/domain`.

## Layout

- `src/server.ts` builds the Fastify app and wires route modules.
- `src/routes/*.routes.ts` contains route groups. Export `register*Routes(app, context)`.
- `src/routes/context.ts` defines shared route dependencies such as auth checks, store access, and error helpers.
- `src/http/schemas.ts` owns JSON schemas used by route definitions.
- `src/http/openapi.ts` builds the OpenAPI document.
- `src/store.ts` defines `ApiStore`, in-memory behavior, and `PersistentApiStore`.
- `src/persistence/*` contains SQLite connection, migrations, and repository adapters.
- `src/integration/*` contains external integration code such as Excel import and WPS connectors.
- `src/seed/*` contains deterministic seed data.
- `db/migrations/*.sql` are ordered SQL migrations.

## Rules

- Keep HTTP concerns in route modules. Put reusable business rules in `@football-club/domain`, `src/application/*`, store, or repository methods.
- Add new route groups as `src/routes/<area>.routes.ts` and register them from `src/server.ts`.
- Update `src/http/schemas.ts` and `src/http/openapi.ts` whenever request/response shapes change.
- Do not edit `dist/` by hand; it is generated by `pnpm --filter @football-club/api build`.
- Reconcile duplicate Finder-style files such as `openapi 2.ts` into the canonical file before finishing work.

## Examples

- Route group: `apps/api/src/routes/data-capability.routes.ts`
- Store contract: `apps/api/src/store.ts`
- SQLite migrations: `apps/api/db/migrations/0001_platform_foundation.sql`
