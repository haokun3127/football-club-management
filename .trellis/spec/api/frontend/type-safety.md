# Backoffice Data Boundaries

The browser is typed React. Use `api<T>` and `ApiError`; validate session shape before rendering the workspace. Keep feature payload types explicit and align them with strict Fastify request/response schemas reused by OpenAPI. New fields need repository, API projection and browser form agreement.

No arbitrary database-table browser, raw SQL payload, privileged header identity or secret dump. Sensitive values require server-side grants on reads, writes, histories and replay responses. Hidden controls alone do not establish authorization.
